## 4. 三项角色/时序/作者层级纠正

### P2FACT-006：客观事件层与主观/心理分析分离

第一遍记录了早期 AI 提案，当时未找到 USER 确认；反向恢复又找到后来 USER 直接要求纯客观链/分析。两条证据处于不同时间、不同角色，均可成立。纠正的是角色和时间，不是否定事实。

### P2FACT-010：position_cycle_id及T/U编号组织148个真实周期

`position_cycle_id` 属于 AI/程序技术身份；136 主动、12 跟单及 T/U 映射后来由 USER 纠正并沿用。第一遍的一条 W02 Prompt 是纯非 USER 执行文本，不能升级成 USER 原创要求。技术事实保留，作者边界修正。

### P2FACT-020：T042—T043跨周期误触反手

关联事实成立；W04 的固定确认句先由 AI 拟写、随后由 USER 执行确认，因此属于“确认行为成立”，不能把整句标为 A 类 USER 原创。该差异不是交易事实冲突。

## 5. 权威与范围边界

- 35 项是历史恢复事实，不是本任务新制定的客观交易链正式定义。
- 事实成立不等于对应文件自动成为权威资产，也不等于未来 schema 已生成；统一记录中的 `future_schema_generated=false` 保持不变。
- USER 原话、USER 确认、AI 技术命名、程序派生和冻结文件结论必须分层；本报告没有把它们合并成单一“USER事实”。
- post-K01 证据只用于验证身份、锁定或后续沿用状态；没有倒灌为 PRE-K01 当时已知事实。
- 没有从 35 项事实反向定义 production 输入、正式交易规则或 USER 筛选条件。
